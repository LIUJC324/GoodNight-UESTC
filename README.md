# 晚安成电 · 自动签到（Windows）

每天 **22:00 和 23:25 各尝试一次**，由 Windows 计划任务静默执行：
把微信切到前台 → 打开「成电智慧学工」小程序 → 进入「晚安成电」→ 点击打卡 →
OCR 确认出现成功提示 → 截图存档。**一旦成功，当天后续的尝试自动跳过。**

**打卡时间段是每天 21:00–23:30**，所以 22:00 开始尝试正好在窗口内。

不需要联网接口、不需要第三方库、不需要填写账号密码。步子是固定录制的，但关键位置
（小程序入口、页面文字）会用 Windows 自带 OCR 按文字定位，界面轻微错位也能点中。

## 一、一次性配置（3 步，约 3 分钟）

### 第 1 步：准备微信

1. 登录电脑版微信（扫码登录，之后只要不退出就一直有效）。
2. **先把「成电智慧学工」小程序窗口关掉**，让微信回到"主窗口 + 未打开小程序"的状态。
3. 让微信窗口保持你晚上习惯的大小（最大化 / 固定大小都行，之后别再大幅缩放）。

### 第 2 步：录制一遍签到流程

双击 **`scripts\record.bat`**：

1. 程序列出检测到的微信窗口，然后等待你按 **F9**。
2. 按 **F9** 开始录制，然后用鼠标正常完成一次签到。
   - 每一步之间自然停顿 0.5～1 秒即可，程序会按你的节奏回放（单步最多等 8 秒）。
3. 签到成功后按 **F10** 结束，程序把步骤写进 `steps.json`。

> 程序只记录**微信进程窗口内**的点击，以及回车 / Esc。桌面上其它点击不会录进去。
> 如果某一步需要输入文字：先把文字复制到剪贴板，到那一步按 **F7**，程序会粘贴并记录。

### 第 3 步：安装计划任务

双击 **`scripts\install_task.bat`**，它会注册名为 `WananChengdianSign` 的计划任务：

- 每天 **22:00** 和 **23:25** 各尝试一次（22:00 失败会发邮件提醒，23:25 是兜底）；
- 用 `pythonw.exe` 静默运行（不弹黑框）；
- 开机错过时间会自动补跑（StartWhenAvailable）；
- 允许唤醒睡眠中的电脑（Wake to Run）。

看到"尝试时间 : 每天 22:00、23:25"就成功了。

### 验证（建议做一次）

| 想确认什么 | 双击 |
| --- | --- |
| 这台电脑允不允许程序模拟鼠标键盘 | `scripts\check_env.bat` |
| 坐标算得对不对（**不会真的点**） | `scripts\test.bat` |
| 完整跑一遍看看 | `scripts\run_now.bat` |

`scripts\run_now.bat` 会真的点，跑完在 `logs\` 里留一张 `last-*.png` 截图；白天测试时会显示
"没看到打卡成功的提示"，这是正常的（还没到 21:00）。

| 条件 | 说明 |

| 电脑开机 | 睡眠可以被计划任务唤醒；关机不行 |

| 22:00 之后别抢鼠标 | 每次尝试会先等你空闲 2 秒（最多等 5 分钟）再动手 |

## 四、图形设置界面（邮箱 + 运行时间）

双击 **`scripts\settings.bat`**，
会弹出一个窗口，直接填就行，不用敲命令行：

- **失败提醒邮箱**
  - 收件邮箱：提醒发到哪里（可以就用你自己的邮箱）；
  - 发件账号：一般和收件邮箱相同；
  - SMTP 服务器 + 端口：填了邮箱后会自动带出（qq.com → smtp.qq.com:465）；
  - 授权码：**不是登录密码**！
    - QQ 邮箱：网页版 → 设置 → 账号 → 开启「SMTP 服务」→ 生成授权码；
    - 163 邮箱：设置 → POP3/SMTP/IMAP → 开启 → 设置授权码；
    - Gmail / Outlook：需要应用专用密码。
  - 不知道授权码是什么、去哪找？见文末 **九、附录：授权码是什么？怎么获取？**
- **自动尝试时间**：默认 22:00 和 23:25，可改成任意 HH:MM；
- 勾选「保存后同时更新 Windows 计划任务时间」，点 **保存并应用** 就生效；
- 点 **发送测试邮件** 可以先验证邮箱配置对不对（收到就说明通了，没收到先看垃圾箱）。

> 授权码会明文保存在本机 `config.json` 里，别把这个文件发给别人。

### 什么时候会收到邮件

- **每天最多一封**：22:00 第一次尝试没成功就发（异常关闭、微信没登录、界面没点到、
  分辨率不对等都会算失败），邮件里写明原因并附上当时的截图；
- 23:25 的兜底尝试不会重复发信；
- 如果你已经手动签了，忽略邮件即可；
- 想连成功也通知：在界面里勾选「成功也通知」。

### 手动改配置（可选）

`config.json` 里的 `email` 段也可以直接编辑：

```jsonc
"email": {
  "enabled": true,
  "to": "you@qq.com",          // 收件地址
  "smtp_host": "smtp.qq.com",
  "smtp_port": 465,
  "username": "you@qq.com",     // 发件账号
  "password": "授权码",          // QQ/163 是授权码
  "on_first_failure": true,     // 第一次失败就发
  "on_success": false,          // 成功也发
  "attach_screenshot": true     // 附上截图
}
```

## 五、它是怎么做到"快且不卡"的

- **低于正常优先级**运行（`BELOW_NORMAL`），几乎不抢 CPU；
- 用**页面稳定检测**代替死等固定秒数：画面连续几帧不变就立刻往下走，
  一次完整流程约 **20–30 秒**（原来是 45 秒以上）；
- 只截取需要的那一小块窗口，不整屏截图；
- 剪贴板用完会**还原**你原来的内容；
- 失败时**只在当天没有后续重试机会（23:00 之后）才弹窗**，白天/前几次失败只写日志；
- 成功一次就写 `state.json`，当天剩下的 5 次尝试 1 秒内退出，不再动鼠标。

## 六、常见问题

**Q：任务跑了，但没签上？**
先看 `logs\last-*.png` 和 `logs\run-*.log`：
- 截图停在微信主窗口 → 小程序没打开；
- 截图停在应用中心 → 「晚安成电」入口没点到，重新录制；
- 截图显示"未到时间" → 还没到 21:00，属于正常；
- 截图显示"已打卡" → 已经签过了，属于正常。

**Q：为什么失败没有弹窗？**
为了不打扰你：配了邮件就以邮件为准；没配邮件时，只有 **23:00 之后**还失败才弹窗。

**Q：邮件没收到？**
1. 打开 `scripts\settings.bat`，点「发送测试邮件」看能不能发出去；
2. 看 `logs\run-*.log` 里有没有「发送邮件失败」和具体错误（授权码错、端口不对、网络）；
3. 检查垃圾箱；QQ 邮箱有时会把自动邮件归类到垃圾邮件。

**Q：改了屏幕分辨率 / 缩放比例后会怎样？**
坐标按 **1920×1080 / 96 DPI** 标定（`steps.json` 的 `screen` 字段）。
分辨率对不上时程序会**直接跳过、不乱点**，并发邮件告诉你；等分辨率恢复或重新录制即可。
（这条是专门为避免"打游戏改分辨率时乱点"加的。）

**Q：小程序窗口被关掉 / 微信被收进托盘？**
程序会自动把隐藏的微信主窗口显示出来，也会重新打开小程序，不用手动点。

**Q：锁屏了怎么办？**
Windows 的锁屏界面是独立的安全桌面，任何自动化都无法点击。两个办法：
1. 设置 → 电源 → 屏幕和睡眠：都设为"从不"，并在"屏幕保护程序"里取消"恢复时显示登录屏幕"；
2. 或者让电脑自动登录（专业版可用 `netplwiz` 取消"必须输入密码"）。

**Q：微信更新 / 小程序改版了？**
重新双击 `scripts\record.bat` 录一遍即可，旧的 `steps.json` 会自动备份成 `steps-backup-*.json`。

**Q：想换时间？**
`install_task.bat -Time 21:50 -Time2 23:20`
（在资源管理器地址栏输入 `cmd` 打开命令行再运行）。

**Q：想确认任务确实存在？**
命令行执行 `schtasks /query /tn WananChengdianSign /v /fo LIST`。

**Q：任务历史显示 `0x1`？**
进程返回 1，代表这次尝试失败（会有下一次尝试），日志里有具体原因。

## 七、原理与安全

- 点击坐标保存为**窗口客户区左上角的像素偏移**（`offset`），窗口移动/最大化都不会偏；
- 关键元素（微信搜索里的小程序入口、页面是否停在「应用中心」、打卡是否成功）用
  **Windows 自带 OCR** 按文字判断，抗界面轻微漂移；
- 微信窗口靠"进程名 + 窗口标题 + 窗口类名"三重匹配定位；微信 4.x 的小程序是独立进程
  `WeChatAppEx.exe`，也已纳入识别；
- 全程用 Windows 原生 `SendInput` 模拟鼠标键盘，和真人操作走同一条路径，不注入、不挂钩、不改微信文件；
- 程序不读取聊天内容、不联网、不需要账号密码；`steps.json` 里只有窗口标题和坐标。

## 八、高级：手工调整 `steps.json`

回放按数组顺序执行，支持这些步骤：

```jsonc
{ "type": "click",  "offset": {"x": 134, "y": 308}, "delay": 1.2, "win": { ... } },
{ "type": "click_verify", "offset": {"x": 208, "y": 552}, "timeout": 15, "win": { ... } },
{ "type": "key",    "key": "esc",   "delay": 0.5, "win": { ... } },
{ "type": "hotkey", "keys": ["ctrl", "a"], "delay": 0.3, "win": { ... } },
{ "type": "paste",  "text": "晚安成电", "delay": 0.3, "win": { ... } },
{ "type": "wait",   "seconds": 2.0 },
{ "type": "wait_stable", "timeout": 15, "win": { ... } },
{ "type": "ensure_text", "text": "应用中心", "back_offset": {"x": 22, "y": 45}, "win": { ... } },
{ "type": "open_miniprogram", "keyword": "成电智慧学工",
  "search_offset": {"x": 151, "y": 57}, "result_offset": {"x": 134, "y": 352}, "tries": 5 }
```

- `offset`：相对窗口客户区左上角的像素偏移（也支持 `rel` 比例、`abs` 绝对屏幕坐标）；
- `delay`：这一步之前等多少秒（回放时会被 `config.json` 的 0.35～8 秒夹住）；
- `click_verify`：点完用 OCR 找"成功/已打卡"，找不到就算这次失败，等下一次计划尝试；
- `win.title`：录制时的窗口标题，匹配不到时会尝试同窗口类的其它微信窗口。

`config.json` 里常改的项：

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `window_wait_seconds` | 15 | 等某个窗口出现的最长时间 |
| `retries` | 0 | 单次运行内部重试次数（重试交给计划任务更省事） |
| `notify_failure` | true | 失败时是否弹窗 |
| `notify_failure_after` | 23:00 | 只有这个时间之后的失败才弹窗 |
| `notify_success` | false | 成功时弹窗 |
| `screenshot_scale` | 2 | 截图缩小倍数，1 = 原分辨率 |
| `keep_logs_days` | 30 | 日志/截图保留天数 |

## 九、附录：授权码是什么？怎么获取？

### 它是什么

**授权码**是邮箱发给「第三方软件」的专用密码，不是你的 QQ / 微信 / 邮箱登录密码。

邮箱厂商默认禁止程序直接用登录密码发信（防盗号），所以给了另一种方式：
你在邮箱网页里生成一串专用码，程序拿这串码去登录 SMTP 服务器发信。
它可以随时作废、重新生成，泄露了也不影响你的邮箱密码。

### 它长什么样

一般是一串 16 位左右的随机字母数字，例如：

```
abcdwxyz12345678
```

只显示一次，生成后建议先复制到记事本。

### QQ 邮箱怎么拿（最常用）

1. 电脑浏览器打开 `mail.qq.com` 并登录；
2. 左上角 **设置** → **账号**（新界面叫「账号与安全」）；
3. 找到 **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务**；
4. 开启 **POP3/SMTP 服务** 或 **IMAP/SMTP 服务**；
5. 按提示做一次**短信验证**；
6. 页面弹出 **授权码**，复制它。

对应的服务器填写：

| 项 | 值 |
| --- | --- |
| SMTP 服务器 | `smtp.qq.com` |
| 端口 | `465` |
| 发件账号 | 你的 QQ 邮箱全称，如 `123456@qq.com` |

### 163 邮箱怎么拿

1. 登录 `mail.163.com`；
2. **设置** → **POP3/SMTP/IMAP**；
3. 开启 **IMAP/SMTP 服务**；
4. 点 **设置客户端授权密码**，短信验证后得到授权码；
5. 服务器填 `smtp.163.com`，端口 `465`。

### Gmail / Outlook

- Gmail：先开启「两步验证」，再生成 **应用专用密码**（16 位），服务器 `smtp.gmail.com:465`；
- Outlook：开启两步验证后生成应用密码，服务器 `smtp.office365.com:587`（界面里把端口改成 587）。

### 在界面里怎么填

打开 `scripts\settings.bat` 后：

| 界面字段 | 填什么 |
| --- | --- |
| 收件邮箱 | 你要收提醒的地址（可以就是自己） |
| 发件账号 | 通常和收件邮箱一样 |
| SMTP / 端口 | 填了邮箱会自动带出，不对再手改 |
| 授权码 | 上面拿到的那串 16 位码（**不是登录密码**） |

填完点 **发送测试邮件**：收到就说明配置成功；收不到先看垃圾箱，再看提示里的错误。

### 安全提示

- 授权码只保存在本机 `config.json` 里，不会上传到任何地方；
- 如果怀疑泄露：回到邮箱设置页，删除/重新生成授权码，程序里改成新的即可；
- 不想配也没关系：不配邮件提醒，签到照样自动跑，只是失败时只能看日志。

### 常见报错

| 现象 | 原因 / 处理 |
| --- | --- |
| `535 Authentication failed` | 授权码填错，或用了登录密码；重新生成一个 |
| `Connection refused` / 超时 | 端口或服务器填错；QQ/163 用 465（SSL） |
| 测试邮件没收到 | 先看垃圾箱；QQ 邮箱常把自动邮件归到垃圾邮件 |
| `SMTP 服务未开启` | 回邮箱设置页把 POP3/SMTP 或 IMAP/SMTP 打开 |
