# 晚安成电 · 自动签到

> 一个在 Windows 上帮「成电智慧学工」小程序完成**晚安成电**打卡的小工具。
> 纯 Python 标准库 + Windows 自带 OCR，不注入、不抓包、不需要账号密码。

**它做什么**：每天 22:00 和 23:25 各尝试一次——打开电脑版微信 → 进入小程序 →
打开「晚安成电」→ 点击打卡 → 用 OCR 确认结果 → 失败时发邮件提醒你。

**它不做什么**：不读取聊天记录、不上传任何数据、不保存学校账号密码。只模拟鼠标键盘，
等同于你自己手动点一遍。

> ⚠️ 本项目是个人自用工具，仅供学习自动化技术使用。请自行确认符合学校相关规定，
> 使用产生的后果由使用者承担。

## 特性

| 特性 | 说明 |
| --- | --- |
| 零第三方依赖 | 只用 Python 标准库 + Windows API（`ctypes` / GDI 截图 / 自带 OCR） |
| 图形设置界面 | 填邮箱、授权码、运行时间，点一下就能更新计划任务 |
| 失败邮件提醒 | 22:00 没签上会发邮件（附失败截图），每天最多一封 |
| 界面漂移可容错 | 关键元素用 OCR 按文字定位，不完全是死坐标 |
| 分辨率保护 | 屏幕分辨率变了直接跳过、不乱点，并发邮件告知 |
| 不打扰 | 低于正常优先级运行、剪贴板用完还原、成功后当天不再重复 |
| 可复盘 | 每次运行都有日志和截图，`verified` 字段标明是否确认签上 |

## 工作原理

```
Windows 计划任务（22:00 / 23:25）
        │
        ▼
微信主窗口 ──搜索──▶ 小程序「成电智慧学工」──▶ 应用中心 ──搜索──▶ 晚安成电
                                                                  │
                                                            点击打卡圆
                                                                  │
                                                          可能需要确认定位
                                                                  │
                                                       OCR + 颜色校验是否签上
                                                                  │
                                            成功 → 记录状态，当天不再尝试
                                            失败 → 发邮件提醒
```

- **窗口定位**：按「进程名 + 窗口标题 + 窗口类名」匹配，兼容微信 4.x
  （主窗口 `Weixin.exe`，小程序为独立进程 `WeChatAppEx.exe`）。
- **点击定位**：坐标保存为窗口客户区左上角的像素偏移，窗口移动、最大化都不受影响；
  微信搜索里的小程序入口用 OCR 找「最近使用过的小程序」那一段里的目标，避免结果行位置漂移。
- **定位弹窗**：点完打卡圆后，小程序可能弹出「正在加载中… / 重新定位 / 确认定位」，
  程序会自动找到「确认定位」并点击；没有弹窗就跳过，不阻塞流程。
- **结果校验**：先 OCR 找「成功 / 已打卡」文字；文字是画布绘制读不到时，
  再看颜色——**中间蓝色状态圆消失、底部出现绿色结果条** 即判定已打卡。

## 环境要求

- Windows 10 / 11
- Python 3.9+（安装 python.org 版本，自带 `tkinter`）
- 电脑版微信 4.x，且**保持登录**
- 屏幕处于解锁状态（锁屏时 Windows 禁止模拟输入）

## 快速开始

### 1. 准备

下载或克隆本仓库，解压到一个固定目录（路径里不要有空格以外的特殊字符）。

```bash
git clone https://github.com/LIUJC324/GoodNight-UESTC.git
cd GoodNight-UESTC
```

### 2. 录制一遍签到流程

双击 `scripts\record.bat`，先**关掉小程序窗口**，然后：

1. 按 **F9** 开始录制；
2. 正常手动完成一次签到（打开小程序 → 晚安成电 → 打卡）；
3. 按 **F10** 结束，步骤写入 `steps.json`。

> 程序只记录微信进程窗口内的点击，以及回车 / Esc。
> 需要输入文字时，先把文字复制到剪贴板，到那一步按 **F7**。

### 3. 配置提醒邮箱（可选）

双击 `scripts\settings.bat`，填写收件邮箱、SMTP 服务器和**授权码**，
点「发送测试邮件」验证，再点「保存并应用」。

授权码不是登录密码，获取方式见文末 [附录](#附录授权码是什么)。

### 4. 安装计划任务

双击 `scripts\install_task.bat`，会注册名为 `WananChengdianSign` 的计划任务：

- 每天 **22:00** 和 **23:25** 各尝试一次；
- `pythonw` 静默运行，不弹黑框；
- 错过时间自动补跑，可唤醒睡眠中的电脑。

### 5. 验证

| 想确认 | 双击 |
| --- | --- |
| 这台电脑能否模拟鼠标键盘 | `scripts\check_env.bat` |
| 坐标是否正确（不会真点） | `scripts\test.bat` |
| 完整跑一遍 | `scripts\run_now.bat` |

运行结果在 `logs\last-*.png`（截图）和 `logs\run-*.log`（日志）里。

### 6. 电脑端定位过不了？改用邮件提醒模式

如果电脑版微信的定位总是落在范围外（学校校验较严时很常见），可以不追求自动打卡，
让电脑只负责**到点提醒**：

双击 `scripts\install_reminder.bat`，注册 `WananChengdianRemind`：

- 每天 **22:00** 和 **23:15** 各发一封提醒邮件；
- 只发信，不操作微信，不点任何东西；
- 你收到后用手机签（手机有真实定位，范围校验能过）。

手动测试：`python wechat_auto.py remind`
卸载：`scripts\uninstall_reminder.bat`

> 想恢复自动打卡，双击 `scripts\install_task.bat` 即可（会重新启用签到任务）；
> 暂停自动打卡：`Disable-ScheduledTask -TaskName WananChengdianSign`。

## 配置说明

`config.json` 关键项：

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `process_names` | `Weixin.exe` 等 | 需要识别的微信进程 |
| `window_wait_seconds` | 15 | 等某个窗口出现的最长时间 |
| `retries` | 0 | 单次运行内部重试次数 |
| `start_idle_seconds` | 2 | 开始前等待用户空闲的秒数 |
| `abort_on_screen_mismatch` | true | 分辨率与录制时不一致就跳过 |
| `notify_failure` | true | 失败时是否弹窗 |
| `notify_failure_after` | 23:00 | 只有这个时间之后的失败才弹窗 |
| `screenshot_scale` | 2 | 截图缩小倍数，1 = 原分辨率 |
| `keep_logs_days` | 30 | 日志/截图保留天数 |
| `email.enabled` | false | 是否启用邮件提醒 |
| `email.to` | — | 收件邮箱 |
| `email.on_first_failure` | true | 第一次失败就发信 |
| `email.on_success` | false | 成功也发信 |

## 常见问题

**Q：任务跑了但没签上？**
先看 `logs\last-*.png`：
- 停在微信主窗口 → 小程序没打开；
- 停在应用中心 → 晚安成电入口没点到，重新录制；
- 停在「正在加载中… / 重新定位 / 确认定位」→ 定位确认弹窗没点上；
- 显示「未到时间」→ 还没到 21:00，属于正常；
- 显示「已打卡」→ 已经签过，属于正常。

**Q：为什么定位显示的是「区政府」这类地标，不是我的宿舍？**
这是**定位源太粗**，不是脚本点错了：

- Windows 台式机的精确定位靠 **Wi-Fi 热点扫描**（比对外面 AP 的位置库）；
  只插网线、无线网卡没有连 Wi-Fi 时，只能退回 **IP 定位**——精度 1~3 公里，
  通常落在区中心、政府大楼这类地标上；
- **改善**：连一个 Wi-Fi（哪怕不用它上网，只要连着），并确认
  「设置 → 隐私和安全性 → 定位」里定位服务和桌面应用权限都已开启；
- 也有可能是小程序本身用服务商的 IP 定位（不经过 Windows），
  那样本机怎么设置都不会变，只有换网络（例如手机热点）才会变；
- 只要学校端不卡精确范围，位置显示有偏差通常不影响打卡结果。

**Q：电脑端签不上，提示「不在范围」？**
电脑版微信小程序没有 GPS，只能按 **IP 归属** 定位，误差常在 1~3 公里，容易落到区中心/地标上，
被学校判定为范围外。手机有真实定位，连同一个 Wi-Fi 就能落在宿舍。

遇到这种情况建议改用「邮件提醒模式」：电脑到点发一封邮件提醒你，用手机手动签（位置真实、不会被判范围外）。

**Q：为什么失败没有弹窗？**
为了避免打扰：配置了邮件就以邮件为准；没配邮件时，只有 23:00 之后的失败才弹窗。

**Q：改了分辨率 / 缩放比例会怎样？**
坐标按录制时的分辨率标定（`steps.json` 里的 `screen` 字段）。分辨率对不上时会
**直接跳过、不乱点**，并邮件告知，等恢复或重新录制即可。

**Q：微信在托盘里 / 小程序被关掉了？**
程序会自动显示隐藏的微信主窗口，并重新打开小程序。

**Q：锁屏了怎么办？**
锁屏是独立安全桌面，任何自动化都无法点击。建议把电源计划设为「从不睡眠」，
并关闭「恢复时显示登录屏幕」。

**Q：微信更新 / 小程序改版了？**
重新双击 `scripts\record.bat` 录一遍，旧的 `steps.json` 会自动备份。

**Q：想改运行时间？**
双击 `scripts\install_task.bat`，或在命令行执行
`install_task.bat -Time 21:50 -Time2 23:20`。

## 已知限制

- 依赖固定分辨率下的界面布局，换分辨率或系统缩放后需要重新录制；
- 定位精度取决于系统和网络环境：没有连接 Wi-Fi 时只能 IP 定位，误差可达公里级，
  显示的位置可能是区中心/地标而不是宿舍，是否影响打卡由学校端判定；
- 小程序用画布绘制文字时 OCR 可能读不到状态，此时改用颜色判断兜底；
- 仅在 Windows 上测试，微信版本迭代可能导致窗口类名变化；
- 锁屏、关机、微信未登录时无法工作。

## 附录：授权码是什么

**授权码**是邮箱给第三方软件的专用密码，不是你的 QQ / 邮箱登录密码。邮箱厂商
默认禁止程序直接用登录密码发信，所以提供了这种“应用专用密码”。

### QQ 邮箱

1. 浏览器打开 `mail.qq.com` 登录；
2. **设置 → 账号**（新界面为「账号与安全」）；
3. 找到 **POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV 服务**；
4. 开启 **POP3/SMTP 服务** 或 **IMAP/SMTP 服务**；
5. 按提示完成短信验证，页面会显示 **授权码**，复制保存。

| 项 | 值 |
| --- | --- |
| SMTP 服务器 | `smtp.qq.com` |
| 端口 | `465` |

### 163 邮箱

设置 → POP3/SMTP/IMAP → 开启 IMAP/SMTP 服务 → 设置客户端授权密码 → 短信验证。

服务器 `smtp.163.com`，端口 `465`。

### Gmail / Outlook

- Gmail：开启两步验证后生成应用专用密码，`smtp.gmail.com:465`；
- Outlook：开启两步验证后生成应用密码，`smtp.office365.com:587`。

### 常见报错

| 现象 | 处理 |
| --- | --- |
| `535 Authentication failed` | 授权码错，或填成了登录密码 |
| 连接超时 | 服务器/端口不对，QQ、163 用 465（SSL） |
| 收不到测试邮件 | 先看垃圾箱，QQ 邮箱常归到垃圾邮件 |
| `SMTP 服务未开启` | 回邮箱设置页开启对应服务 |

> 授权码以明文保存在本机 `config.json`，请勿把该文件分享给他人。
