## 这一轮做了什么

### 提速（约 45 秒 → 20~30 秒）

- 用 `wait_stable`（画面连续几帧不变才算加载完）替代固定 `sleep`
- 只截取窗口那一块，不整屏截图
- 微信搜索的等待从 1.8s 降到 1.1s，点结果后的窗口轮询 0.3s 一次

### 不打扰 / 不卡

- 进程优先级降到 `BELOW_NORMAL`
- 剪贴板用完自动还原
- 失败不再每次都弹窗，只在 23:00 后（当天没机会再试）弹
- 成功后当天剩余尝试直接跳过，不再动鼠标

### 稳定性（关键）

- 微信 4.x 小程序是独立进程 `WeChatAppEx.exe`，已纳入窗口识别
- 主窗口判定改为"必须够大 + 标题精确匹配微信"，避免误认 `Weixin` 小窗
- 微信窗口被收进托盘会自动显示
- 点不到前台时用 `SetWindowPos` 置顶兜底（不依赖前台权限）
- 微信搜索里的小程序入口改为 **OCR 按文字定位**（面板位置会漂移，坐标不可靠）
- 小程序会记住上次页签，新增 `ensure_text`：找不到「应用中心」就点返回箭头退回
- 打卡结果改为 **OCR 语义校验**：必须看到"成功 / 已打卡"才算成功，
  排除"今日打卡""未到打卡时间段"等干扰；校验不过就等下一次计划尝试
